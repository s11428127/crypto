# BTC 風險控制台

比特幣合約的風險計算與技術分析工具。純前端、不連帳戶、不能下單。

## 為什麼有這個東西

技術分析不能告訴你「哪裡進場最賺錢」。它能做的只有兩件事：

1. 把盤感變成可以檢查的條件（趨勢方向、結構位置、動能衰竭）
2. 把風險固定住（止損放哪、部位開多大、爆倉價在哪）

第二件事比第一件重要。訊號再準，部位開錯大小一樣會歸零 ——
所以這個專案從風險計算做起，訊號是後面的事。

## 目前做到哪

- [x] **第一階段：風險計算**（`learn.html`）
  - 部位體檢：爆倉價、距離爆倉、槓桿放大倍率
  - 從止損反推部位大小（隱含槓桿 = 風險% ÷ 止損距離%）
  - 可行性檢查：交易所最小下單量對小資金的限制
  - 價格軸圖：進場／止損／爆倉／止盈畫在同一條軸上
  - 每個公式都有中文逐步推導
- [x] **第二階段：即時行情與訊號**（`index.html` 主控台）
  - Binance 公開端點 + WebSocket 即時價，Binance 掛掉自動切 Bybit
  - K 線圖（EMA20/50/200、成交量、即時價格線），15m / 1H / 4H / 1D 可切
  - RSI、MACD、ATR、布林、結構高低點
  - 多時間框架對齊：1D 定方向 → 4H 定結構 → 15m 定時機，不同調就標「觀望」
  - 進場計畫卡：進場區間／止損／TP1 TP2／部位大小／爆倉價／手續費 R 佔比
- [ ] 第三階段：交易日誌（記錄每筆的 R 倍數，算真實勝率與期望值）
- [ ] 第四階段：幣種篩選器（掃出偏多／偏空的清單）
- [ ] 第五階段：回測（沒回測過的指標就是玄學）

## 本機執行

```bash
npm run serve      # http://127.0.0.1:8099
npm test           # 純函式層的驗算（77 項）
npm run test:e2e   # 瀏覽器檢查，四種寬度（需要先啟動 serve）
```

不需要安裝任何相依套件。計算層（`risk.js` / `indicators.js` / `plan.js`）
都是純函式，沒有 DOM、沒有網路，可以直接被 Node 測試。

E2E 用 Playwright 攔截請求餵模擬行情，所以離線也跑得起來；
真實的交易所連線請在自己的瀏覽器開頁面確認。

## 安全性

這個工具**不會**連接你的交易所帳戶、不需要 API key、不能下單、不能提幣。
行情只走交易所的**公開端點**（K 線、24h 行情、資金費率、未平倉量、下單限制），
即時價用公開的 WebSocket 行情頻道。全部都不需要身分驗證。

## 免責

這是計算與學習工具，不是投資建議。所有輸出都是根據你輸入的參數算出來的數學結果，不預測市場。
爆倉價會因保證金模式、維持保證金檔位、手續費與資金費而與此處略有差異，**請以交易所 App 顯示的為準**。
